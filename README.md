# Pitch Visualizer Pro

Pitch Visualizer Pro is an AI-powered platform that converts narrative pitch content into structured, cinematic storyboards.

## Features
- FastAPI backend with modular architecture.
- Narrative segmentation and classification engine.
- Modern glassmorphism-inspired UI for storyboard generation.
- Real-time text-to-visual conversion.

## Tech Stack
- **Backend:** Python, FastAPI
- **Frontend:** HTML, Vanilla CSS, JS (Vite)
